A fast drop-in replacement for `csv-reader` 1.0.0. Same answers, built with bulk operations: `charCodeAt` scans, `indexOf` hops and `slice`/`join` instead of per-character string concatenation, with no per-field array allocations. Roughly 10x the baseline's parse time on the practice corpus.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
